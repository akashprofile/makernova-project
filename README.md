# 🩺 Sehat Mitra - AI Powered Doctor Prescription System  
### _MakerNova 3.0 Hackathon Project (July–September 2025)_

An AI-powered healthcare assistant designed to help users get preliminary medical insights and prescription advice based on their symptoms.  
Developed as part of **MakerNova 3.0 Hackathon** — a collaborative innovation challenge aimed at building tech-driven solutions for real-world problems.

## 🚀 Project Overview

The **AI Doctor Prescription System** allows users to input their symptoms in natural language and receive:
- Possible disease predictions  
- Doctor-style prescription advice  
- Suggestions for further medical consultation  

The system combines **Natural Language Processing (NLP)**, **Machine Learning (ML)**, and **rule-based logic** to provide accurate recommendations in an intuitive web interface.

---

## 🧠 Key Features

- **NLP-based Symptom Extraction:**  
  Automatically detects and classifies symptoms from natural language input.

- **Disease Prediction Model:**  
  Uses trained ML classifiers (e.g., Decision Tree Classifier) to predict possible diseases.

- **Smart Prescription Generator:**  
  Provides medication and advice using a rule-based prescription logic.

- **Interactive Frontend:**  
  Built with HTML, CSS, and JS — offering a user-friendly interface with animations and icons.
